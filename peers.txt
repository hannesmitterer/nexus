# This file contains multi-addresses of IPFS nodes that should receive
# the Peacobond distribution files. Each line should contain one peer
# multi-address in the format:
#   /ip4/<IP_ADDRESS>/tcp/<PORT>/p2p/<PEER_ID>
# or
#   /ip6/<IPv6_ADDRESS>/tcp/<PORT>/p2p/<PEER_ID>
# or
#   /dns4/<DOMAIN>/tcp/<PORT>/p2p/<PEER_ID>
#
# Lines starting with # are treated as comments and will be ignored.
# Empty lines are also ignored.
