# Deployments Directory

This directory contains deployment artifacts for the Nexus Governance Framework.

## Structure

Each network has its own subdirectory containing deployment artifacts:

```
deployments/
├── hardhat/          # Local Hardhat network deployments
├── mumbai/           # Polygon Mumbai testnet deployments
├── polygon/          # Polygon mainnet deployments
└── README.md         # This file
```

## Deployment Artifacts

Each deployment creates a JSON file with the following structure:

```json
{
  "address": "0x...",
  "deploymentData": {
    "contract": "GovernanceMetricsRegistry",
    "network": "polygon",
    "timestamp": 1234567890,
    "deployer": "0x...",
    "ggcMultisig": "0x...",
    "config": {
      "quorum": "6700",
      "treTarget": "30",
      "pvMax": "500",
      "isfMin": "75"
    }
  },
  "recordHash": "0x...",
  "abi": [...]
}
```

## Usage

Deployment artifacts are automatically generated by the synchronous deployment script:

```bash
npx hardhat run scripts/deploy/deploy-governance-sync.js --network <network>
```

## Security

⚠️ **Important**: Deployment artifacts contain sensitive information including contract addresses and configuration. Ensure these files are properly secured and version controlled.

## Verification

To verify a deployment:

1. Check the deployment artifact for the network
2. Verify the contract address on the blockchain explorer
3. Compare the `recordHash` with on-chain governance records
4. Validate the configuration matches expected values

## Governance Records

All deployments should have corresponding governance records anchored on-chain using the `anchorGovernanceRecord` function with the deployment's `recordHash`.
